# 1일차 — 탑다운 AI Survival Arena 목표 설계

## 오늘의 질문

> AI가 무엇을 보고, 어떤 행동을 선택해야 출구까지 안전하게 도달할 수 있을까?

오늘은 복잡한 AI를 구현하지 않습니다. 이후 FSM, Utility AI, 강화학습, LLM 에이전트가 함께 사용할 탑다운 문제를 정의합니다.

## 예시 환경

```text
+-------------------+
|       위험        |
|  에너지           |
|        NPC        |
|              출구 |
+-------------------+
```

모든 요소는 Unity 기본 도형과 색으로 표시합니다. 첫날에는 출구, 에너지, 위험 지대만 사용하며 벽·경비병·열쇠는 추가하지 않습니다.

## 반드시 정의할 항목

### 1. 목표

제한 시간 또는 에너지 안에 출구에 도달합니다.

### 2. 관측 정보

AI가 판단할 때 알 수 있는 정보입니다.

- 현재 위치와 남은 에너지
- 출구의 상대 위치
- 가장 가까운 에너지의 상대 위치
- 위험 지대의 위치 또는 거리

### 3. 행동

- 위, 아래, 왼쪽, 오른쪽 이동
- 대기

### 4. 성공과 실패 조건

- 성공: 출구에 도달한다.
- 실패: 제한 시간이 끝나거나 에너지가 소진된다.
- 제약: 위험 지대를 지날 수는 있지만 패널티를 받는다.

### 5. 평가 지표

- 탈출 성공 여부
- 걸린 시간 또는 이동 횟수
- 위험 지대 진입 횟수
- 남은 에너지

## 생성형 AI로 설계 검토하기

아래 질문을 출발점으로 사용하되, 본인의 규칙에 맞게 수정해도 됩니다.

```text
탑다운 생존 Arena의 NPC AI를 설계하고 있다.
목표는 에너지가 소진되기 전에 출구에 도달하는 것이다.
NPC는 현재 위치, 남은 에너지, 출구·에너지·위험 지대의 상대 위치를 안다.
행동은 상하좌우 이동과 대기다.
이 설계에서 빠진 예외 상황이나 모호한 규칙을 찾아줘.
```

AI의 답변을 정답으로 취급하지 않습니다. 제안 중 하나 이상을 반영하거나 제외하고, 그 이유를 제출 파일에 기록합니다.
