# 게임 AI 스터디 커리큘럼

## 공통 프로젝트: Escape Lab

스터디 전체에서 하나의 **미로 탈출 환경**을 단계적으로 확장합니다. 동일한 문제를 규칙 기반 AI, 머신러닝 기반 AI, LLM 에이전트로 각각 다루고, 마지막에는 같은 기준으로 검증합니다.

## 5차시 구성

| 차시 | 주제 | 환경과 실습 목표 | 주요 산출물 |
| --- | --- | --- | --- |
| 1차시 | Unity와 AI의 연결 구조 이해 | 미로 탈출 문제의 목표·관측·행동·성공 조건을 정의한다. | AI 목표 설계서, 첫 PR |
| 2차시 | 게임 AI의 기본 구현 | FSM으로 탐색, 이동, 회피, 복구 행동을 구현한다. | 규칙 기반 탈출 AI |
| 3차시 | 머신러닝 기반 게임 AI | 동일 환경에서 보상 함수를 설계하고 학습 에이전트를 만든다. | 학습 결과 및 규칙 기반 AI와의 비교 |
| 4차시 | LLM 에이전트와 Unity 연동 | LLM이 고수준 행동을 결정하고 Unity가 제한된 행동을 실행한다. | 자연어 지시 기반 에이전트 |
| 5차시 | AI 기반 게임 플레이 검증 | 여러 맵과 조건에서 AI를 반복 실행하고 결과를 비교한다. | 검증 보고서와 최종 PR |

## 공통 설계 원칙

- 초기 환경은 시작점, 출구, 고정 벽만 있는 작은 격자형 미로로 시작합니다.
- 새 기능은 이전 차시의 환경 위에 추가합니다. 매 차시마다 새 게임을 만들지 않습니다.
- AI는 목표를 달성하는 방법을 결정하고, Unity는 이동·충돌·승패 같은 게임 규칙을 처리합니다.
- 모든 과제는 개인 브랜치와 Pull Request로 제출합니다.

## AI 활용 원칙

생성형 AI는 답안을 대신 만드는 도구가 아니라 설계와 검증을 돕는 협업 도구로 사용합니다.

- 설계의 빠진 조건과 예외 상황을 검토받습니다.
- 알고리즘 또는 코드의 동작을 설명받고 직접 확인합니다.
- 제안 중 반영한 내용과 제외한 이유를 과제에 기록합니다.
- AI가 만든 결과를 검증 없이 그대로 제출하지 않습니다.
