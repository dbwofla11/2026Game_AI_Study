# 2026 Game AI Study

몬스터가 **무엇을 할지 고르는 방법**과 **어느 길로 움직일지 찾는 방법**을 배우는 스터디입니다. 생활 속 비유부터 시작하고, 간단한 그림과 예제로 개념을 설명합니다. 구현 자체보다 각 방법의 역할과 동작 원리를 이해하는 데 집중합니다.

## 강의계획

기본 계획은 **10회차, 회차별 약 90분**입니다. 아래는 이번 게임 AI 개념 강의의 회차 구성이며, 기존 1회차 자료는 위 링크에 보존했습니다. 일정과 설명 속도에 따라 회차별 분량을 조정할 수 있습니다.

공통 게임 예제는 순찰하다가 적을 발견하면 따라가고, 가까워지면 공격하며, 다치면 회복하는 경비병입니다. 벽·문·계단·좁은 통로를 추가하면서 판단과 이동의 문제를 차례로 살펴봅니다.

| 회차 | 주제 | 쉽게 설명할 핵심 내용 | 이해 확인 |
| --- | --- | --- | --- |
| 1 | Game AI 구조와 FSM | 주변 살피기, 기억하기, 행동 고르기, 길찾기의 관계. 현재 상태와 바뀌는 조건 | 순찰에서 추적, 추적에서 공격으로 언제 바뀔까? |
| 2 | Behavior Tree · 행동 나무 | 차례대로 하기와 하나 고르기. 다 했어·못 하겠어·하는 중이라는 답. 메모장과 행동 중단 | 따라가다 다치면 무엇부터 확인하고 어떤 일을 멈출까? |
| 3 | 그래프와 A* · 길찾기 | 장소와 연결. 온 값과 남을 값의 예상. 후보 비교, 더 싼 길의 기록, 이전 칸으로 길 복원 | 다음에는 어느 칸을 살펴볼까? 완성된 길은 어떻게 만들까? |
| 4 | HPA* · 큰 지도에서 길찾기 | 지도를 구역으로 나누기. 출입 지점을 연결해 큰 길부터 찾기. 상세 길과 지도 변경 처리 | 구역을 묶으면 무엇이 줄고, 어떤 준비가 더 필요할까? |
| 5 | GOAP · 목표를 이루는 행동 계획 | 지금 상황과 원하는 상황. 행동에 필요한 조건, 행동 후 변화와 비용. 실패하면 계획 다시 세우기 | 탄약이 없는데 공격하려면 무엇을 먼저 해야 할까? |
| 6 | Steering과 Context Steering | 목표 쪽으로 움직이기와 주변 장애물 피하기. 방향별 가고 싶은 정도와 위험 비교 | 길 전체를 찾는 일과 지금 움직일 방향을 고르는 일은 어떻게 다를까? |
| 7 | 공간 표현과 NavMesh | 칸·지점·복셀·걸을 수 있는 바닥으로 지도 표현하기. 몸 크기, 경사, 계단과 지도의 자세함 | 작은 몬스터가 지나간 길을 큰 몬스터도 지나갈 수 있을까? |
| 8 | Recast 생성 과정 | 지형을 칸으로 바꾸고, 못 걷는 곳을 빼고, 걸을 수 있는 바닥을 다각형으로 만들기 | 좁은 통로와 낮은 천장은 어느 과정에서 걸러질까? |
| 9 | Detour와 동적 환경 | NavMesh에서 길 요청하기. 지나갈 바닥과 실제 이동 지점. 움직이는 이웃과 바뀐 지형 처리 | 다른 몬스터가 길을 막을 때와 새 벽이 생길 때 어떻게 대응할까? |
| 10 | 통합 설계와 디버깅 | 감지, 행동 선택, 목적지, 경로, 이동을 연결하기. 실패 원인과 갱신 시점 확인 | 멈춘 경비병의 문제를 어떤 순서로 확인할까? |

### 수업 진행 방식

- 복습과 생활 비유: 10분
- 그림으로 개념 설명: 25분
- 작은 예제의 동작을 단계별로 확인: 25분
- 한계와 자주 생기는 문제: 15분
- 퀴즈와 토론: 15분

수식과 영어 이름은 쉬운 예시를 이해한 뒤 소개합니다. 한 장에 여러 원리를 몰아넣기보다, 상황이 어떻게 바뀌는지 한 단계씩 보여줍니다.

## 공통 사례 — Top-down AI Survival Arena

모든 차시는 하나의 가상 탑다운 Arena 사례를 중심으로 설명합니다. 외부 에셋이나 실제 Unity 구현은 필수가 아닙니다.

| 요소 | 의미 |
| --- | --- |
| 에이전트 | AI가 행동을 결정하는 NPC |
| 출구 | 최종 목표 |
| 에너지 | 생존에 필요한 자원 |
| 위험 지대 | 피하거나 비용을 감수해야 하는 영역 |
| 장애물·경비병 | 판단을 복잡하게 만드는 환경 요소 |

이 사례를 통해 아래의 공통 구조를 반복해서 해석합니다.

```text
환경 → 관측 → 판단 정책 → 행동 → 상태 변화와 보상
```

## NYPC 수준을 위한 핵심 도달점

대회에 도전하려면 최소한 다음 질문에 답할 수 있어야 합니다.

- 환경의 관측·행동·목표·보상을 명확히 정의할 수 있는가?
- FSM, Behavior Tree, Utility AI, 경로 탐색의 적용 상황을 구분할 수 있는가?
- MDP와 정책, 가치, Actor-Critic의 역할을 설명할 수 있는가?
- PPO의 Advantage, Clipping, Entropy가 학습 안정성에 기여하는 이유를 설명할 수 있는가?
- 학습 보상과 실제 성공률이 다를 때 원인을 가설로 세울 수 있는가?
- 랜덤 맵이나 숨겨진 조건에서 일반화 여부를 검증해야 하는 이유를 아는가?

9~11일차가 경진대회 준비의 중심입니다. PPO 구현법을 암기하는 것보다, 보상·관측·평가 방식이 잘못됐을 때 어떤 현상이 나타나는지를 해석하는 능력이 중요합니다.

## 생성형 AI 사용 원칙

생성형 AI는 강의 내용을 대신 답하는 도구가 아니라 사고를 점검하는 도구로 사용합니다.

- 상태 전이 또는 보상 설계의 빠진 조건을 검토받습니다.
- 알고리즘의 장단점과 예상 실패 사례를 비교합니다.
- AI의 제안 중 반영한 내용과 제외한 이유를 기록합니다.
- 답변을 그대로 신뢰하지 않고 강의 개념과 사례로 검증합니다.
